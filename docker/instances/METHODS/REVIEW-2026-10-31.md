## Selected instance: openthread-13494-late-order — Method 1

The original problem description, upstream fix, real source, full regression file, controls, existing candidate patch, and prior report were inspected before validation. Original mechanism: virtual-time polling finishes before the background reader queues completion, producing a false timeout. The upstream fix adds a bounded real-time queue drain.

Synthetic mechanism: the drain prepends each arriving line instead of appending it. Completion detection and bounded waiting remain functional, but the response list is reversed. This violates ordering rather than availability/completion and does not reproduce the original timeout bug. The existing regression asserts exact ping and diagnostic response order. This causal distinction and expected oracle were described before the fresh injection.
